개인정보처리방침

시행일: 2026년 9월 12일

Obsidian Sermon Sync는 운영자 본인의 목회 연구를 지원하기 위한 개인용 비상업적 자동화입니다.

수집 및 접근하는 데이터

사용자가 승인한 Google Drive의 파일 이름, 폴더 구조, 파일 메타데이터 및 지정된 설교 PDF 내용에 접근합니다. Google 계정 비밀번호는 수집하지 않습니다.

데이터 이용 목적

Drive에서 아직 정리되지 않은 설교 PDF를 확인하고, 내용을 요약·구조화한 Markdown 노트를 생성하여 사용자가 지정한 Drive 폴더에 저장하는 데만 사용합니다.

처리 및 전송

선택된 PDF 내용은 노트 생성을 위해 Google Gemini API로 전송될 수 있습니다. 생성된 노트와 처리 결과 알림은 사용자가 지정한 Google Drive 및 Telegram 계정으로 전달될 수 있습니다.

보관 및 공유

앱 운영자는 Google 사용자 데이터를 별도의 데이터베이스에 판매하거나 광고 목적으로 사용하지 않습니다. 데이터는 요청된 자동화 처리와 결과 저장에 필요한 범위에서만 사용되며, 법적 요구가 없는 한 제3자에게 판매하거나 임의로 공유하지 않습니다.

보안

OAuth 자격 증명과 API 키는 GitHub Actions의 암호화된 비밀 저장소에 보관합니다. 자동화 대상은 사용자가 지정한 폴더로 제한하고, 민감한 목회 행정 자료는 기본 처리 대상에서 제외합니다.

Google API 제한적 사용

Google API에서 받은 정보의 사용 및 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 준수합니다.

접근 철회 및 삭제

사용자는 Google 계정의 보안 설정에서 언제든지 앱의 접근 권한을 철회할 수 있습니다. 생성된 Markdown 파일은 사용자가 직접 관리하고 삭제할 수 있습니다.
