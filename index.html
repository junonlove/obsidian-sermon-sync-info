Obsidian Sermon Sync

개인 목회 연구를 위해 Google Drive의 설교 PDF를 확인하고, 구조화한 Markdown 노트를 사용자의 Obsidian 보관함 폴더에 저장하는 개인용 자동화 도구입니다.

사용 목적

  • 지정된 Google Drive 설교 폴더에서 아직 정리되지 않은 PDF 확인
  • 설교 내용을 요약·구조화하여 Markdown 노트 생성
  • 생성한 노트를 사용자가 지정한 Drive 폴더에 저장

접근 범위

자동화는 사용자가 직접 승인한 Google 계정에서만 작동합니다. 접근 권한은 설교 파일을 읽고 생성된 Markdown 파일을 저장하는 데만 사용됩니다.

운영 방식

이 앱은 개인 사용을 위한 비상업적 자동화이며, 일반 사용자에게 계정 생성이나 서비스를 제공하지 않습니다.
