## scan-ocr.html — 스캔 PDF 변환기

스캔 PDF를 Markdown(.md)과 검색 가능한 PDF로 바꾸는 단일 HTML 파일. 내려받아 브라우저로 열면 바로 쓴다(인터넷 연결 필요: 라이브러리와 언어 데이터를 jsdelivr에서 받음).

- OCR 엔진: Tesseract(무료, 내 컴퓨터에서 처리) 또는 Claude API(유료, API 키 필요)
- 언어: 한글, 영어, 헬라어, 히브리어
- 검색 PDF는 원본 쪽 위에 보이지 않는 글자층만 겹쳐서 원본 화질과 용량을 그대로 유지
